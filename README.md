### How I work with AI

- **Ship it, don't demo it.** A model is only useful after it's behind an API, with fallbacks, logging, and a product surface.
- **Right model for the job.** Cheap + fast for classification. Stronger models when the writing or ranking has to be good.
- **Integrations are the product.** Google APIs, webhooks, email, SaaS tenants — AI sits on top of that plumbing.
- **Keep the system boring.** Fancy prompts on a messy backend is how things break at 2am.
